Experimental `temporalio.contrib.streams`: `notify_on_append(notification_log=True)` writes a notification log entry with each append, in the same store step, in place of the producer's notification. `StreamDriver(client).run()` reads that log through Core and calls the server's `NotifyStreams` for the streams that moved, until it is cancelled. `RedisStreams` takes `notify_doorbells`.
Experimental `temporalio.contrib.streams`: a `workflow_reader()` reads first and attaches to the stream's notifier only when a read comes back empty, then reads once more with no wait before it sleeps.
