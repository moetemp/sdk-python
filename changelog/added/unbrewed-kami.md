Add experimental `activity.Info.workflow_task`, the Workflow Task attempt in which a Worker dispatched a Local Activity.
Core: A local activity's `ActivityTask.Start` has `workflow_task` (field 20), with the started event id, attempt and start time of the workflow task in which Core dispatched it. `workflow_task` also has `previous_started_event_id`, the started event id of the run's last completed workflow task, and `failed_tasks`, the started event ids of the run's last 100 failed or timed out workflow tasks. Retries that Core runs locally keep the value. Core leaves it unset for other activities.
