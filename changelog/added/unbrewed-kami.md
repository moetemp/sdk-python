Add experimental `activity.Info.workflow_task`, the Workflow Task attempt in which a Worker dispatched a Local Activity.
Core: A local activity's `ActivityTask.Start` has `workflow_task` (field 21), with the started event id, attempt and start time of the workflow task in which Core dispatched it. `workflow_task` also has `previous_started_event_id`, `previous_attempt` and `previous_started_time` of the run's last completed workflow task, and `failed_tasks`, the started event ids of the run's last 100 failed or timed out workflow tasks. Retries that Core runs locally keep the value. Core leaves it unset for other activities.
Core: Experimental external storage drivers now receive the workflow or standalone activity a payload is stored for, as the `target` on `StorageDriverStoreContext` and `StorageDriverSelectContext`.
Core: Experimental external storage (requires the `experimental` feature). `DataConverter::with_external_storage` offloads payloads at or above a size threshold to a user-supplied `StorageDriver`, replacing them in history with small references that workers and clients resolve transparently. See `ExternalStorage` for current limitations. This API may change without notice.
Core: Workers report the types of the external storage drivers configured on their client's data converter in worker heartbeats.
