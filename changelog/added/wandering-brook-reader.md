Experimental: `temporalio.contrib.streams.nexus.StreamReader` reads the stream a Nexus operation returns from Workflow code. `next()` waits on the operation's progress, reads through the stream service as Nexus operations of the Workflow, so replay hands over the same batches, and returns `None` once the operation completed. `supersessions` reports where a producer's later attempt took over, and a record that cannot be decoded raises `StreamRecordError`. Record bodies reach the Workflow decoded, so the Workers on both sides need the same payload codec.
